# Retail Sales SQL Analysis

**Tools Used:** MySQL

Analysis of a 50,000 row retail sales dataset (2020–2024) using SQL 
to uncover revenue trends, top products, and customer behaviour.

## Key Insights
- Electronics was the highest revenue category
- Top 3 most profitable cities identified
- Credit Card was the most popular payment method
- Completed orders accounted for the majority of all transactions

## Questions Answered
1. Which product category generates the most revenue?
2. What are the top 3 most profitable cities?
3. List all sales made in 2023, ordered by date
4. How many orders were placed per payment method?
5. Which product had the highest total quantity sold?
6. What is the average order value per gender?
7. Find all categories where total revenue is above $500,000
8. Which city generated the most profit?
9. What is the total revenue per category?
10. How many orders were Returned vs Completed?

## Skills Demonstrated
SQL querying, Aggregations, GROUP BY, HAVING, 
ORDER BY, Filtering, Date functions
